# Manim Animator & Code Architect

Esta skill toma el Storyboard generado por `manim-director` y lo transforma en código Python ejecutable, limpio, modular y tipado, utilizando exclusivamente **Manim Community Edition (v0.18+)**.

---

## 1. Principios de Arquitectura del Código

1. **Sin Escenas Monolíticas (SRP):**
   * Divide el método `construct(self)` en fases narrativas explícitas (`setup_environment`, `intro_sequence`, `main_transformation`, `outro_sequence`).
   * Extrae la creación de objetos complejos (tarjetas, grafos, interfaces, componentes) a funciones auxiliares puras o clases que extiendan `VGroup`.
2. **Posicionamiento Relativo Estricto:**
   * Prohibido hardcodear tuplas o arreglos de coordenadas mágicas (`np.array([2.5, -1.3, 0])`).
   * Utiliza composición con `VGroup`, `arrange`, `next_to`, `to_edge`, `to_corner` y `align_to`.
3. **Robustez ante LaTeX:**
   * A menos que el usuario especifique explícitamente fórmulas matemáticas avanzadas, usa `Text` o `MarkupText` para títulos, descripciones y diagramas. Esto evita que el render falle en sistemas donde TeXLive no está instalado.
4. **Respeto a APIs Modernas:**
   * Consulta obligatoria: [manim_ce_cheat_sheet.md](./references/manim_ce_cheat_sheet.md) para no utilizar métodos obsoletos (ej: jamás usar `ShowCreation` o `TextMobject`).

## 2. Plantilla Estándar de Código (`src/scenes/<nombre_video>.py`)

Cada archivo de escena generado debe seguir esta estructura canónica:

```python
"""
Animation: <Nombre del Video>
Generated by Manim Animator Skill
Preset: <Preset Utilizado>
"""

from manim import *

# ==========================================
# CONSTANTES DE DISEÑO Y PALETA
# ==========================================
BG_COLOR = "#0D1117"
PRIMARY = "#58A6FF"
SECONDARY = "#3FB950"
ACCENT = "#F0883E"
TEXT_COLOR = "#F0F6FC"
MUTED_COLOR = "#484F58"


# ==========================================
# COMPONENTES REUTILIZABLES (VGroups)
# ==========================================
def create_feature_card(title_text: str, subtitle_text: str, color: str = PRIMARY) -> VGroup:
    """Construye una tarjeta visual compuesta para motion graphics."""
    box = RoundedRectangle(
        corner_radius=0.15,
        width=3.6,
        height=2.2,
        fill_color="#161B22",
        fill_opacity=0.95,
        stroke_color=color,
        stroke_width=2.0
    )
    title = Text(title_text, font_size=20, weight=BOLD, color=TEXT_COLOR)
    title.next_to(box.get_top(), DOWN, buff=0.35)
    
    sub = Text(subtitle_text, font_size=14, color=MUTED_COLOR)
    sub.next_to(title, DOWN, buff=0.2)
    
    return VGroup(box, title, sub)


# ==========================================
# ESCENA PRINCIPAL
# ==========================================
class MainScene(Scene):
    def construct(self):
        # 1. Configuración de Cámara y Fondo
        self.camera.background_color = BG_COLOR
        
        # 2. Pipeline de Ejecución de la Narrativa
        self.phase_intro()
        self.phase_core_concept()
        self.phase_conclusion()

    def phase_intro(self):
        title = Text("Título Principal", font_size=38, weight=BOLD, color=PRIMARY)
        title.to_edge(UP, buff=0.8)
        
        self.play(Write(title), run_time=1.2)
        self.wait(1.0)
        self.title = title

    def phase_core_concept(self):
        card1 = create_feature_card("Módulo A", "Procesamiento inicial", PRIMARY)
        card2 = create_feature_card("Módulo B", "Salida validada", SECONDARY)
        
        group = VGroup(card1, card2).arrange(RIGHT, buff=1.2)
        group.move_to(ORIGIN)
        
        arrow = Arrow(card1.get_right(), card2.get_left(), buff=0.15, color=ACCENT)
        
        self.play(FadeIn(card1, shift=UP * 0.3), run_time=0.8)
        self.play(Create(arrow), run_time=0.6)
        self.play(FadeIn(card2, shift=DOWN * 0.3), run_time=0.8)
        self.wait(1.5)
        
        # Guardar referencias para limpieza posterior
        self.core_group = VGroup(group, arrow)

    def phase_conclusion(self):
        self.play(
            FadeOut(self.core_group),
            FadeOut(self.title),
            run_time=0.8
        )
        final_msg = Text("¡Sistema Completado!", font_size=32, color=SECONDARY)
        self.play(FadeIn(final_msg, scale=1.2), run_time=1.0)
        self.wait(2.0)
```

## 3. Lista de Verificación (Checklist) antes de entregar código

Antes de dar el código por finalizado:
- [ ] ¿Todos los imports provienen de `from manim import *`?
- [ ] ¿Se definió el color de fondo (`self.camera.background_color`) acorde al preset?
- [ ] ¿Todas las posiciones usan `to_edge`, `next_to`, o `arrange` en lugar de coordenadas fijas?
- [ ] ¿Todas las animaciones usan `.animate` en mutaciones (en vez de mutar el objeto dentro de `self.play(...)` sin `.animate`)?
- [ ] ¿Hay pausas controladas (`self.wait(...)`) entre ideas para permitir digestión visual?
- [ ] ¿El archivo fue guardado en `src/scenes/<nombre_video>.py`?
